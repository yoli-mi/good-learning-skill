# 资料检索

## 从书目线索到实际材料

先从用户给的 ISBN、书名、作者或主编、出版社、出版年、版次和封面／目录识别目标书；不同版次、上下册与套装不能仅凭相似标题视为同一本。

当用户要求在 Z-Library 和 GitHub 查找时，在可访问范围内分别检索。先用 ISBN（有无连字符），再用完整书名、去掉副标题的书名、作者或命题组名称，并组合版次、出版社、出版年；中文书可尝试简繁体、旧书名和常见异写。继续放宽词序与标点，分别检索主标题、专业类别、作者及“上册／下册／套装”，不能因套装 ISBN 或版次不同漏掉单册条目。可访问时使用站内搜索，查看相关结果与推荐条目；站内无法访问时明确说明检索范围，不把搜索引擎未收录当成站内不存在。用户提供候选链接后优先核对该链接，并修正先前的否定结论；若无法打开，只能据链接文字确认候选标题，版次、ISBN 和文件内容仍标为待核。对 GitHub 同时查仓库描述与文件路径，防止把只有书目引用或其他同名比赛的仓库当成书籍。发现候选后核对题名、作者、版次、卷册和内容类型；明确区分“有书目记录”“有样章”“有可用全文”。不要因搜索页无结果就声称整个网站绝无此书，也不要为核对而绕过访问限制。

如果经过上述不同线索仍未在这两个来源找到可核对的对应书目，按用户要求写出：**未在Z-library和Github上查到到对应书目。** 这句话只说明本次可访问渠道的检索结果；若已找到对应书目但没有可用全文，应如实说明，不能套用“未查到”。列出尝试过的主要检索线索，方便用户复核。

随后查出版社、作者或主办方、学校图书馆、开放教材与合法公开课程；用户需要链接时给出直达页并标明它是全文、样章、在线阅读、书目页还是购买／馆藏入口。检查 GitHub 文件的来源与授权。不要指引获取或下载未经授权的教材副本，也不要把未核实的镜像站说成官方入口。用户只要网址时不要代为下载。

## 考试与竞赛不只找书

对全国性考试、大学科目考试和大型竞赛，优先查主办方当年的通知、考试大纲、组别与报名规则，再查主办方或学校公开的历年真题及解析、样题、开放课程、讲义、练习题库和可信的开源备考项目。类似“大学生数学竞赛”和“大学生数学建模竞赛”的名称要核对，避免混入另一赛事。英语四六级等考试要核对当年适用的官方考试说明，并寻找听力、阅读、写作等实际训练资源；不要只列教材。

按用户目标和剩余时间筛选少量真正可用的资源，说明用途、适用组别／版本和访问条件。时效性强的赛程、规则、收费与资料链接应在使用时重新核实。找不到某本书不等于无法制定计划：可用已确认的考纲、真题、开放课程或用户材料形成注明覆盖边界的初版方案。
