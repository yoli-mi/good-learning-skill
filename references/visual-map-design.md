# 导图设计

先回答“读者看完这张图应理解什么关系”，再定图式。知识清单适合显示模块与前置关系；备考计划适合时间路径与反馈循环；每日课程适合概念到练习的学习路径。当日总结导图应同时展示所学知识点的条件与方法，以及错题对应的误判和订正规则；没有真实错题时明确标出示例性质和掌握状态待验证。不要仅把六个同样的方框围着中心排列，也不要为装饰而增加线条。

把正文压缩成 4—7 个主节点，节点用短语，不抄整句。只在能帮助理解时增加第二层信息；完整解释留在正文。总结图可采用中心主题向左右展开的分支：知识规则在主层，模拟或真实错题以清楚的标签附在对应分支，不把错误另堆成一张表。先确定阅读方向，再画主路径与分支，避免交叉线。区分标题、节点标题和补充文字，使用一致的对齐、间距和线宽；配色以中性色为底，少量低饱和颜色区分知识模块，用文字标签同时说明颜色含义。页面四周留安全边距，让图面有呼吸感，并保证缩小查看时仍能辨认主干。

每张导图至少检查两次：先看缩略图，确认结构和主路径在几秒内可辨；再按实际查看尺寸看中文、数学符号、连接线和边界。发现问题时优先调整节点文案、位置与留白，再考虑增加视觉元素。课程内的导图内容须与课程 PDF 正文同步；独立总结图须与当日课程、错题记录及真实反馈状态同步。

设计参考：[Mindmap Skill](https://github.com/galiacheng/mindmap-skills/blob/main/skills/mindmap/SKILL.md) 的短语化与层级选择、[Canvas Design Skill](https://github.com/anthropics/skills/blob/main/skills/canvas-design/SKILL.md) 的空间与字体层级、[Anthropic-Style Diagram Skill](https://github.com/lfboo/anthropic-diagram/blob/main/anthropic-diagram/skill.md) 的清晰图式、[Figma 设计系统指南](https://static.figma.com/uploads/b45ca996363483a82c3ab9ef6e3bcf072ade549c) 的字体与间距原则。只采用适合本项目的原则：课程等 PDF 仍按 LaTeX 规则输出，当日总结思维导图独立用 SVG／PNG 制作。
